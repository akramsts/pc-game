# Gree Runner (PC)

The PC version of **Gree Runner** — an endless 2D runner game. Jump over obstacles, chain "perfect" jumps for bonus points, and chase your high score.

## About

This is the desktop build of Gree Runner, sharing the same gameplay, scoring, themes, and sound design as the original release — built as a standalone PC app for full-screen play with keyboard and mouse.

## How to Play

Your score climbs automatically the longer you survive. Jump cleanly over an obstacle at height to build a **perfect streak** for multiplying bonus points — misjudge it and it's game over.

| Action | Control |
|---|---|
| Jump | `Space`, `↑`, or click |
| Start / Restart | `Enter` or the on-screen button |
| Pause / Resume | `P` |
| Mute / Unmute Sound | `M` |

## Features

- **Endless procedural gameplay** — obstacles spawn continuously, with speed ramping up the longer you survive
- **Perfect jump streaks** — chain well-timed jumps for multiplying bonus points
- **Milestone callouts** — pop-up messages at score milestones (100, 200, 500, 800, 1200+)
- **Persistent high score** — saved locally, no account needed
- **3 built-in themes** — Obsidian, Amber, and Platinum
- **Sound effects** — retro-style effects, fully mutable
- **Keyboard and mouse controls**
- **Fully offline** — no internet connection required after install

## Installation

1. Download the latest release for your platform (Windows / macOS / Linux) from the [Releases](https://github.com/akramsts/pc-game/releases) section.
2. Extract the archive (if zipped).
3. Run the executable (`GreeRunner.exe` on Windows, or the equivalent app/binary on macOS/Linux).
4. Play!

## Requirements

- Windows 10+, macOS 11+, or a modern Linux distro
- ~50 MB free storage
